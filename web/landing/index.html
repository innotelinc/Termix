Termix — Self-hosted, plugin-based server management.

A self-hosted server-management console: SSH terminals, file management, tunnels and plugins in one browser surface, with a plugin API for the tools a team adds itself.

View on GitHub Quick start 
docker compose up -d

Server tools are one SSH client per tab.

Terminals, files and tunnels share one authenticated console.

Every team has a tool the console does not have.

The plugin API is the extension point instead of a fork.

A management console is a second door into every host.

It sits behind the deployment's SSO and keeps its own audit trail.
